# Teknomac Machinery Website — Demo

A polished static-style React/Vite demo website for the Teknomac machinery brand.

## Stack
- React
- Vite
- CSS (custom responsive design)
- Local Teknomac logo asset

## Run locally
1. Install Node.js 18+ (Node 20+ recommended).
2. Extract this ZIP.
3. Open a terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite (normally http://localhost:5173).

For a production build:

```bash
npm run build
npm run preview
```

## Included demo features
- Responsive desktop/tablet/mobile layout
- Sticky navigation + mobile menu
- Machinery/product catalogue with category filters
- Product detail modal
- Industry/application cards
- About/engineering approach section
- Contact/enquiry form with demo success state
- Locally enhanced Teknomac logo
- Self-contained CSS illustrations for machinery, so the demo does not depend on external image hosting

## Content note
Product categories and some terminology are inspired by the public product/application structures of RINGSPANN India, NORD DRIVESYSTEMS and MineralX Flowtech. The Teknomac branding, product names, descriptions, specifications, company details and statistics in this demo are illustrative/dummy content and should be replaced before production use.
